# CloudPal AI – Your Cloud & DevOps Learning Friend

CloudPal AI is a beginner-friendly, browser-based learning assistant designed to help students and developers learn Cloud Computing, AWS, Microsoft Azure, DevOps, Docker, Kubernetes, Linux, and other related technologies.

It provides built-in explanations, interactive quizzes, and interview practice through a simple chatbot interface.

**No API keys, tokens, installations, or backend configuration required!**

## Features

* **Interactive Chatbot:** Ask questions about cloud and DevOps technologies.
* **Cloud Computing:** Learn cloud concepts and service models.
* **AWS:** Explore popular Amazon Web Services.
* **Microsoft Azure:** Understand Azure services and concepts.
* **DevOps Learning:** Explore DevOps tools and practices.
* **Docker:** Learn containerization and useful Docker commands.
* **Kubernetes:** Understand container orchestration.
* **Linux:** Learn basic Linux commands.
* **Interactive Quizzes:** Test your technical knowledge.
* **Interview Practice:** Practice common technical interview questions.
* **Responsive Design:** Works on desktop, tablet, and mobile devices.
* **No Token Required:** Uses a built-in knowledge base instead of an external AI API.
* **Offline Support:** Works directly in your browser without an internet connection.

## Getting Started

No installation or additional software is required.

### Step 1: Clone the Repository

```bash

```

### Step 2: Open the Project Folder

```bash
cd CloudPal-AI
```

### Step 3: Run the Application

Open `index.html` directly in your web browser.

Your CloudPal AI application is ready to use.

## How It Works

CloudPal uses a predefined JavaScript knowledge base to identify supported topics and display relevant answers.

The application includes:

* Rule-based chatbot responses.
* Predefined multiple-choice quizzes.
* Technical interview questions.
* Interactive chat interface.

**Note:** CloudPal AI is currently a rule-based educational assistant, not a live generative AI model. Its responses are limited to the topics and answers included in its JavaScript knowledge base.
